# Cotimel — guía para huéspedes

Sitio estático, sin dependencias. Para verlo localmente, abrí `index.html` en un navegador. En Vercel se puede importar este repositorio y desplegarlo como proyecto estático, sin build command.

## Antes de publicar

- Confirmar que las fotos y el orden del recorrido sean correctos.
- El botón de WhatsApp ya apunta al número configurado en `index.html`.
- La propiedad ofrece self check-in. Las instrucciones y los datos de acceso se envían por el chat de Booking unas horas antes del ingreso; no están publicados en esta página.
- El nombre de red y la contraseña del WiFi se envían por WhatsApp antes de la llegada; no están publicados en esta página.
- El enlace público no tiene inicio de sesión. No poner códigos de acceso ni contraseñas aquí. Un PIN implementado solo en el navegador se puede saltar; para proteger el contenido hace falta protección del lado del servidor y una clave compartida con los huéspedes.
- Revisar el destino de Waze y reemplazarlo por un enlace directo a Cotimel si ya tienen uno guardado.

Las fotos están en `images/` y se sirven junto con el sitio estático.
